CEP Address Lookup API

A basic Java terminal application that consumes an address lookup API using a Brazilian ZIP code (CEP).

This project was created as my first experience consuming an external API with Java.

About

The application allows the user to enter a Brazilian CEP and retrieves the corresponding address information through an API.

Technologies

Java

HTTP Requests

External REST API

JSON

How it works

The user enters a CEP in the terminal.

The application sends a request to the address API.

The API returns the address data.

The application displays the information in the terminal.

Purpose

This project was built for learning purposes, focusing on:

Making HTTP requests with Java

Consuming REST APIs

Working with JSON responses

Practicing Java in a terminal application

Getting Started

Clone the repository and run the project using your preferred Java IDE or terminal.

git clone <repository-url>
cd <project-folder>


Then compile and run the Java application.
